# Hi, I'm Atakan Aktakka 👋

**Full-Stack Developer** · Computer Engineer · İzmir, Türkiye

I'm a full-stack developer focused on the .NET ecosystem. I like building software that turns real business processes into clean, reliable digital workflows — from the database and APIs all the way to web, desktop, and mobile interfaces.

### What I work on

- **Cross-platform apps** — web and mobile applications with ASP.NET MVC, Blazor, and .NET MAUI
- **Backend & APIs** — RESTful services, layered and Onion architectures, MS SQL data modeling
- **Engineering tools** — calculation-heavy apps that bring technical workflows to mobile devices

### Tech Stack

**Mobile & Desktop:** .NET MAUI · Flutter · Windows Forms · Unity
**Database:** MS SQL Server · MySQL
